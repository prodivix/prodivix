本文冻结 G4 多模态输入、媒体派生、Provider content-block normalization、生成媒体候选、实时媒体 session 与
安全/评测边界。它不让 AI 或 `@prodivix/ai` 重新拥有 Binary Asset、Renderer、Browser、Evidence 或 Workspace。

## 背景

`mediaType + byteLength` 只能说明 Context 中有一段媒体 bytes，不能证明模型看见了什么。真实链路可能经过
解码、缩放、裁剪、颜色转换、PDF page render、OCR、转录、抽帧、压缩或 Provider 自己的 media ingestion。
任一阶段都可能丢失信息、改变成本或引入 prompt injection。

Prodivix 又是视觉开发工具。截图可以帮助模型判断视觉结果，但像素、坐标和自然语言描述不是 Canonical Workspace
target。生成图片、音频或视频也不能直接进入 Workspace；它们必须经过现有 G2 Binary Asset truth、scanner、
provenance、proposal、approval 与 Atomic Commit。

当前外部能力参考包括 [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses)、
[Gemini video understanding](https://ai.google.dev/gemini-api/docs/video-understanding) 与
[Gemini Live API](https://ai.google.dev/gemini-api/docs/live-api/get-started-sdk)。外部页面会变化；Prodivix只冻结
modality profile、adapter/transform digest与 conformance fixture实际消费的语义。

## 决策摘要

多模态输入使用 content-addressed source 与有损/无损 transformation receipt：

```text
canonical / derived / user / external media source
  -> validated source descriptor
  -> deterministic bounded transform chain
  -> model-ready representation
  -> Context item with data-only instruction boundary
  -> exact Provider content blocks + usage receipt
```

多模态输出使用候选资产链：

```text
model/provider media output
  -> untrusted generated artifact candidate
  -> G2 materialize / verify / scan / sanitize
  -> typed Agent asset proposal
  -> human approval / Workspace Transaction / Atomic Commit
```

任何 media bytes、OCR/transcript、坐标 action 或 Provider file reference 都不能绕过这两条链路。

## 1. Modality 与 capability profile

```ts
type AgentModalityKind =
  | 'text'
  | 'code'
  | 'raster-image'
  | 'svg'
  | 'screenshot'
  | 'pdf'
  | 'document'
  | 'audio'
  | 'video'
  | 'accessibility-tree';

type AgentModalityProfile = Readonly<{
  modalityProfileId: AgentModalityProfileId;
  kind: AgentModalityKind;
  direction: 'input' | 'output';
  acceptedMediaTypes: readonly string[];
  transformPolicyDigest: CanonicalDigest;
  hardLimits: AgentMediaLimits;
  providerRepresentationDigest: CanonicalDigest;
  profileDigest: CanonicalDigest;
}>;
```

G4 capability slices：

| Profile                       | G4 Exit 要求 | 边界                                                                 |
| ----------------------------- | ------------ | -------------------------------------------------------------------- |
| `g4-core-text-tools`          | Required     | text/code、structured output、client-hosted typed tools              |
| `g4-visual-input`             | Required     | raster image、screenshot；不得以坐标获得写 authority                 |
| `g4-document-input`           | Required     | PDF/document page selection、render/OCR receipt                      |
| `g4-generated-asset-output`   | Optional     | image/audio/video 只能形成 G2 asset candidate                        |
| `g4-audio-input-output`       | Optional     | bounded file/recording；无 ambient microphone                        |
| `g4-video-input`              | Optional     | bounded duration/frame sampling；无 ambient camera                   |
| `g4-realtime-audio-video`     | Optional     | server-authorized ephemeral session；partial output 无 proposal 权限 |
| `g4-accessibility-tree-input` | Optional     | 只消费 Browser/Verification owner 的 sanitized projection            |

Required 表示首次 G4 closure 的三个 native Provider/model configurations 必须分别取得该 exact profile 的
`release-evaluated` qualification。Optional profile 不阻塞 core closure，但产品只有在对应 qualification 未过期时
才能宣称支持；未评测 profile 不能继承 core 状态。

## 2. Media source descriptor

```ts
type AgentMediaSourceDescriptor = Readonly<{
  mediaSourceId: AgentMediaSourceId;
  kind: AgentModalityKind;
  authority: AgentContextAuthority;
  source: AgentGroundingReference;
  workspaceRevision?: WorkspaceRevisionVector;
  contentDigest: CanonicalDigest;
  mediaType: string;
  byteLength: number;
  dimensions?: Readonly<{ width: number; height: number }>;
  pageCount?: number;
  durationMs?: number;
  frameRate?: DecimalString;
  sampleRate?: number;
  channelCount?: number;
  sensitivity: AgentSensitivity;
  sourceTrace?: SourceTraceRef;
  provenanceRef?: AssetProvenanceRef;
  descriptorDigest: CanonicalDigest;
}>;
```

来源规则：

- Workspace Asset 只引用 `@prodivix/assets` 验证过的 digest/size/media identity，不从 signed URL 推断 identity；
- screenshot、trace frame、PDF render 和 accessibility tree 是 revision/run/viewport-bound derived artifact，不是
  Workspace truth；
- user upload 在 materialize/verify/scan 前保持 untrusted，不能因 MIME extension 获得可信类型；
- external URL/file/search result 始终是 `external-untrusted`，其 metadata、alt text、EXIF、PDF attachment 和
  embedded link 都没有 instruction authority；
- source 无法稳定定位或 bytes 无法取得 content digest 时不能成为 apply-capable Context item；
- active SVG、HTML document、macro、embedded JavaScript、external font/resource 必须按 G2 sanitizer policy
  隔离；SVG 可作为 code/text 与安全 raster rendition分别提供，但不能在模型或预览路径执行脚本。

## 3. Transformation lineage

```ts
type AgentMediaTransformationReceipt = Readonly<{
  transformationId: AgentMediaTransformationId;
  transformerId: string;
  transformerVersion: string;
  transformerDigest: CanonicalDigest;
  operation:
    | 'decode'
    | 'resize'
    | 'crop'
    | 'color-convert'
    | 'rasterize'
    | 'page-select'
    | 'ocr'
    | 'transcribe'
    | 'frame-sample'
    | 'compress'
    | 'redact';
  parametersDigest: CanonicalDigest;
  inputDigest: CanonicalDigest;
  outputDigest: CanonicalDigest;
  outputMediaType: string;
  outputByteLength: number;
  loss: 'none' | 'bounded-lossy' | 'unknown';
  omittedRegions?: readonly AgentMediaOmission[];
  diagnosticRefs: readonly DiagnosticRef[];
  receiptDigest: CanonicalDigest;
}>;

type AgentMediaRepresentation = Readonly<{
  sourceDescriptorRef: AgentMediaSourceDescriptorRef;
  transformationReceiptRefs: readonly AgentMediaTransformationReceiptRef[];
  finalContentDigest: CanonicalDigest;
  finalMediaType: string;
  providerBlockDigest: CanonicalDigest;
  representationDigest: CanonicalDigest;
}>;
```

规则：

1. 每一步输入必须等于上一步输出；chain 顺序进入 representation digest。
2. transform 有像素、页数、时长、帧数、CPU/time/memory 与 output byte hard limits。
3. OCR/transcript 是 derived text item，保留媒体 source/transform lineage；它不替代原件，也不自动变成 user intent。
4. page/frame selection 必须记录选中和省略范围；“未看到”与“确认不存在”严格区分。
5. Provider 自己执行不可观察 transform 时，在 ADR 66 `AgentContextTransformReceipt` 标记
   `provider-reported | unknown`；关键内容处理未知时不能形成可信 apply proposal。
6. 同一 source/transform policy 的 deterministic transform 应 byte-stable；依赖随机算法时必须绑定 seed/runtime，
   否则不用于长期 Evidence。
7. 浏览器截屏必须绑定 target revision、renderer/Browser identity、viewport、DPR、color scheme、locale、font set、
   animation/reduced-motion state 与 capture instant。

## 4. Multimodal Context item

```ts
type AgentMultimodalContextItem = Readonly<{
  itemId: AgentContextItemId;
  modalityProfileRef: AgentModalityProfileRef;
  authority: AgentContextAuthority;
  mediaRepresentationRef: AgentMediaRepresentationRef;
  contentDigest: CanonicalDigest;
  sensitivity: AgentSensitivity;
  instructionBoundary: 'user-intent' | 'data-only';
  sourceTrace?: SourceTraceRef;
  omissionRefs: readonly AgentContextOmissionRef[];
}>;
```

system/developer policy 不通过图片、PDF、音频或视频传递。除 explicit bounded user intent text 外，多模态 bytes、
OCR、transcript、caption、alt text、QR、watermark、metadata、字幕和 tool media result 全部固定为 `data-only`。

Prompt/adapter 必须明确隔离不同 block，不允许：

- 把图片中的“忽略上方规则”提升为 system/developer instruction；
- 根据 PDF 表单、EXIF、字幕或音频要求签发 grant/approval；
- 把隐藏 layer/white-on-white text 当作可信配置；
- 因 Provider 返回“我看到了 Secret/授权”而跳过 source/policy validation；
- 将模型对媒体的描述当作媒体 content digest、OCR truth 或 G3 Evidence。

## 5. Visual grounding 与 canonical target

截图用于观察结果，不是作者态 target resolver。视觉 proposal 必须最终引用：

- PIR/Route/NodeGraph/Animation/Code/Asset 的 typed identity；或
- revision-bound SourceTrace/renderer semantic mapping；或
- 明确标记为 unresolved 的 human-review assumption。

像素坐标、bounding box、颜色近似和 OCR label 可以作为 bounded observation，但不能直接成为 Command path。
无法把视觉目标解析回 typed owner/target 时，Agent 只能解释或请求人工选择，不能“点击这个位置”完成生产修改。

视觉比较必须区分：

- deterministic structural/behavioral authority：G3 Plan/Evidence/Closure；
- screenshot perceptual metric：derived quality signal；
- aesthetic/usability judgment：ADR 69 的 blind human rubric。

任何模型或视觉 judge 自报“像素一致”“设计更好”都不能替代 exact artifact identity 和 required human/deterministic
evidence。

## 6. Generated artifact candidate

```ts
type AgentGeneratedArtifactCandidate = Readonly<{
  candidateId: AgentGeneratedArtifactCandidateId;
  taskId: AgentTaskId;
  runId: AgentRunId;
  generation: number;
  producingInvocationId: AgentInvocationId;
  capabilityQualificationDigest: CanonicalDigest;
  inputRepresentationDigests: readonly CanonicalDigest[];
  promptPolicyDigest: CanonicalDigest;
  providerArtifactRef: AgentProviderArtifactRef;
  declaredMediaType?: string;
  declaredByteLength?: number;
  providerSafetyReceiptRef?: AgentProviderSafetyReceiptRef;
  provenanceClaims: readonly AgentUntrustedProvenanceClaim[];
  candidateDigest: CanonicalDigest;
}>;
```

Candidate 是 untrusted service state，不是 Asset/Workspace/Evidence。采纳链必须：

1. callback-bound 下载或读取 Provider output；signed URL/value 不进入 Workspace/trace；
2. 由 G2 materializer 重新计算 bytes digest、size、media type；
3. 运行 decompression-bomb、malware、active-content、dimension/duration 与 media-policy scanner；
4. 必要时产生 deterministic sanitized/derived representation；
5. 保存 Provider/model/capability/input/prompt-policy lineage 和 scanner receipt；
6. 生成 typed Asset domain proposal，而不是 file write/URL patch；
7. human preview/approval exact绑定最终 bytes/provenance/usage/cost/target；
8. 经一个可逆 Workspace Transaction、Outbox 与 Atomic Commit 成为 canonical Asset reference。

Provider 对版权、原创性、训练数据、人物身份或安全性的自然语言声明只是 untrusted claim。未知 license/provenance
必须显示为 unknown；不得由模型虚构 SPDX/license 或用“AI generated”替代实际使用权判断。

## 7. Audio、video 与 realtime session

文件式 audio/video 输入遵循同一 source/transform/Context contract。Realtime 额外要求：

- production apply session 通过 server/native gateway 获取 callback-bound ephemeral authorization；长期 Provider key
  不进入 Browser；
- session 绑定 Task/Run/generation、capability qualification、media policy、device selection 与 hard duration/cost；
- microphone/camera 必须由用户显式选择和可见授权，禁止 ambient/background capture；
- partial transcript、partial audio、interrupted turn 和 barge-in output 都是 ephemeral，只有 final normalized turn
  才能进入 Context；
- session reconnect 创建新 transport generation，旧 socket/frame/callback 被 fencing；
- voice identity、speaker recognition、biometric inference 默认不属于 G4；
- realtime session 永远不能把口头“批准”解析成 `AgentApprovalDecision`；生产 approval 仍在 ADR 65 独立表面完成；
- audio/video raw bytes 默认不进普通 audit；只保存 bounded encrypted artifact reference、digest、duration、
  redaction class 与 retention receipt。

## 8. Media usage 与 budget

媒体预算使用 ADR 66 `AgentUsageVector`，至少限制：

- source/final bytes；
- image count、width/height、total pixels；
- document count/pages/rendered pixels/OCR characters；
- audio seconds/sample rate/channels/transcript size；
- video seconds/input frames/sampled frames/frame pixels；
- transform compute/memory/time；
- Provider upload/storage bytes 与 retention；
- generated artifact count/bytes；
- billable media units 与 currency cost。

输入被压缩或抽帧后，logical source volume、processed representation volume 与 Provider billable volume分别记录。
不能只记录“等价 token”，也不能用 cache/low-detail 模式隐藏实际省略内容。

## 9. Evaluation 与 qualification

ADR 69 为每个 modality profile建立独立 slice。Required visual/document slice 至少覆盖：

- 不同尺寸、DPR、颜色模式、字体与 viewport 的 screenshot；
- crop/resize/compression/OCR/page selection 的 transform lineage；
- PDF text layer、scan page、mixed image/text、attachment/link/hidden layer；
- image/PDF/QR/metadata 中的 prompt injection；
  -视觉目标到 typed target/SourceTrace 的正确解析与 hallucinated target；
- omitted page/region/frame 的不确定性表达；
- media budget exhaustion、corrupt file、bomb/oversize、unsupported codec；
- Provider 对同一 media block normalization 的 differential conformance；
- 视觉 proposal 经 G3 deterministic verification；
- sampled subjective cases 的 blind human rubric。

Optional audio/video/realtime/generated-output slice 只有单独通过后才能进入产品 support claim，不能借 required
visual profile 折算。

## 10. Security 与 fail-closed matrix

| 风险                             | 必须行为                                                                   |
| -------------------------------- | -------------------------------------------------------------------------- |
| image/PDF/audio/video injection  | 所有 embedded instruction 保持 data-only；grant/approval/tool scope 不改变 |
| hidden layer/metadata/QR         | 扫描并标记；不能提升 authority                                             |
| transform lineage gap            | Context incomplete/blocked；不猜测原始内容                                 |
| omitted page/frame/region        | 记录 omission；不能声称完整检查                                            |
| media bomb/codec exploit         | G2 scanner/isolated transform；失败前不进入 Provider                       |
| active SVG/document              | sanitize/rasterize/isolate；不执行脚本、宏或外部资源                       |
| visual coordinate write          | unresolved；必须映射 typed target 或请求人工选择                           |
| generated artifact direct write  | candidate only；G2 verify/scan + proposal/approval/Transaction             |
| signed Provider URL leakage      | callback-bound resolver；URL/value 不进入 Workspace、prompt、trace         |
| ambient microphone/camera        | 禁止；explicit visible device grant + hard session budget                  |
| partial realtime output          | ephemeral；finalize 前不进入 proposal/approval                             |
| provider media retention unknown | restricted data blocked；qualification 降级                                |
| model provenance/license claim   | untrusted/unknown；不得伪造 license 或审计事实                             |

## 11. 拒绝的方案

### 只给 Context item 增加 `mediaType`

拒绝。它没有 modality limit、transform lineage、omission、injection、Provider representation 或非 token usage。

### 让视觉模型按坐标操作编辑器完成作者态修改

拒绝。坐标绕过 typed target、domain planner、exact approval 和 Canonical Workspace write path。

### 把 Provider output URL 直接写进 Asset document

拒绝。URL 可过期、可替换、可能泄露 credential，且没有 G2 digest/scan/provenance authority。

### 用模型生成的 caption 代替 SourceTrace 或 Evidence

拒绝。caption 是不可信解释，不能证明媒体来源、revision、实际行为或验证结果。

### 把所有多模态能力作为一个布尔值评测

拒绝。visual、document、audio、video、realtime 和 generated output 的 transport、安全、成本与质量完全不同。
