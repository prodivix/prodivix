# Rootless Test probe dependencies

This fixture installs the Vitest package used to attest the rootless Test report
adapter. `rootlessProbeSnapshot.ts` carries both files into the revision-bound
snapshot and installs them with `npm ci --ignore-scripts --no-audit --no-fund`.
The real React/Vue Preview, Test and Build Golden snapshots run separately in
the same rootless Gate.

Vitest 4.1.9 and Vite 8.1.3 match the repository's validated toolchain. The Vite
override binds every compatible Vite peer to that exact declared dependency.
Without it, npm 10.9.8 can resolve another Vite version while loading Vitest's
optional peer graph, enter newer devtools/Vitest 5 peers, and crash in Arborist
with `Cannot read properties of null (reading 'edgesOut')`.

Regenerate `package-lock.json` with npm 10.9.8 from this directory after an
intentional dependency update, then run `npm ci` with the flags above. Keep
the lockfile generated by npm; do not hand-edit it or disable peer validation.
The lock retains platform-specific optional packages, including Linux x64
native bindings required by the actual CI runner.
