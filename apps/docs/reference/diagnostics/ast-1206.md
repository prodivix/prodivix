# AST-1206 Asset 投影超出 hard budget

## 快速信息

| 名称     | 说明             |
| -------- | ---------------- |
| 前缀     | AST              |
| 范围     | 二进制资源       |
| 严重程度 | `error`          |
| 阶段     | `git projection` |
| 可重试   | 否               |

## 含义

AST-1206 表示 Asset 投影超出 hard budget。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

投影超过 Asset 数量或总字节 hard budget

## 建议操作

拆分资源集合或移除超大资源后重新投影

- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
