# AI-6013 Provider usage 需要 reconciliation

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `task`  |
| 可重试   | 是      |

## 含义

AI-6013 表示 Provider usage 需要 reconciliation。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

token/media/tool/compute/storage usage receipt 缺失、相互矛盾或 Provider terminal 后仍未知

## 建议操作

等待或执行 usage reconciliation；在完成前不要扩大预算或关闭 Run

- 可复现时的最小文档或配置
