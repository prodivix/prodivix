# BHV-5002 Recorder draft 已因 revision 变化失效

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `warning` |
| 阶段     | `record`  |
| 可重试   | 否        |

## 含义

BHV-5002 表示 Recorder draft 已因 revision 变化失效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

draft 基于的 Workspace/Semantic revision 不再是 current，无法安全生成 Transaction

## 建议操作

在新 revision 上重新解析并审查后提交

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
