# VER-5002 Evidence 中检测到 Secret 或敏感数据

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `fatal`   |
| 阶段     | `promote` |
| 可重试   | 否        |

## 含义

VER-5002 表示 Evidence 中检测到 Secret 或敏感数据。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

candidate、log、trace、network、screenshot/source/artifact 中命中 Secret/credential/禁止 PII policy

## 建议操作

撤销相关 credential，修复 adapter/fixture/redaction 后创建全新 attempt

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
