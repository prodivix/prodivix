# VER-9001 未分类的 Verification 异常

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | VER                |
| 范围     | 验证闭环           |
| 严重程度 | `error`            |
| 阶段     | `runtime-selected` |
| 可重试   | 否                 |

## 含义

VER-9001 表示 未分类的 Verification 异常。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

未匹配到稳定语义的内部异常

## 建议操作

复制 code、plan/cell/attempt/request id 和安全详情后上报

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
