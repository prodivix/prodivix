# VER-2002 Verification exemption 已过期或不适用

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | VER      |
| 范围     | 验证闭环 |
| 严重程度 | `error`  |
| 阶段     | `policy` |
| 可重试   | 否       |

## 含义

VER-2002 表示 Verification exemption 已过期或不适用。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

exemption expired、revoked、scope/revision/rule 不匹配或试图降低 forbidden hard cut

## 建议操作

修复问题或通过正式 authoring 创建新的有界 exemption

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
