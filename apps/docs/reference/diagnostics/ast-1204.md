# AST-1204 Asset checkout path 冲突

## 快速信息

| 名称     | 说明             |
| -------- | ---------------- |
| 前缀     | AST              |
| 范围     | 二进制资源       |

## 含义

AST-1204 表示 Asset checkout path 冲突。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

document identity、checkout path、大小写或 reserved path 发生冲突

## 建议操作

重命名冲突资源后重新投影
