# BHV-1001 BehaviorScenario 无效

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | BHV        |
| 范围     | 行为场景   |
| 严重程度 | `error`    |
| 阶段     | `validate` |
| 可重试   | 否         |

## 含义

BHV-1001 表示 BehaviorScenario 无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Scenario 缺失必需字段、kind 未知、id 重复、composition 循环、步骤不可达或超过结构预算

## 建议操作

打开 Scenario Issues，修复标记的步骤、引用或结构
