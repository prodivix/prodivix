# SVR-3002 mutation invocation identity 与 durable ledger 冲突

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | SVR                |
| 范围     | 鉴权与服务端运行时 |
| 严重程度 | `error`            |
| 阶段     | `mutation replay`  |
| 可重试   | 否                 |

## 含义

SVR-3002 表示 mutation invocation identity 与 durable ledger 冲突。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

invocation 的 origin、snapshot、function 或 input identity 与 durable ledger 记录冲突

## 建议操作

重新发起一次新的操作，不要重复提交同一次 mutation
