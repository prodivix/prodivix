# AST-1001 canonical asset 缺少 verified materialization

## 快速信息

| 名称     | 说明              |
| -------- | ----------------- |
| 前缀     | AST               |
| 范围     | 二进制资源        |
| 严重程度 | `error`           |
| 阶段     | `materialization` |
| 可重试   | 是                |

## 含义

AST-1001 表示 canonical asset 缺少 verified materialization。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

编译、导出、预览或本地 blob 读取时，canonical asset document 没有可验证的 materialization

## 建议操作

确认该资源已完成上传与同步后重试；若仍不可用，重新导入该文件
