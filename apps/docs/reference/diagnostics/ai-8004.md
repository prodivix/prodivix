# AI-8004 Agent rollback 被阻止

## 快速信息

| 名称     | 说明           |

| 前缀     | AI             |
| 范围     | AI 助手        |

## 含义

AI-8004 表示 Agent rollback 被阻止。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

reverse Transaction 未预授权、digest/current revision/actor authority 不兼容，或存在 intervening change

## 建议操作

审阅 current Workspace 与 reverse diff，人工创建新的 rollback proposal
