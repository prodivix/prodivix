# AI-7005 Agent 自我审批或权限升级被拒绝

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | AI         |
| 范围     | AI 助手    |
| 严重程度 | `error`    |
| 阶段     | `approval` |
| 可重试   | 否         |

## 含义

AI-7005 表示 Agent 自我审批或权限升级被拒绝。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

model/tool/plugin 尝试充当 approver、伪造用户同意、扩大 grant 或复用其他 preview 的 decision

## 建议操作

在独立 Proposal review surface 由已认证用户审批 exact preview

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
