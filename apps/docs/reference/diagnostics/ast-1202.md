# AST-1202 同一 Asset document 收到重复 materialization

## 快速信息

| 名称     | 说明             |
| -------- | ---------------- |
| 前缀     | AST              |
| 范围     | 二进制资源       |
| 严重程度 | `error`          |
| 阶段     | `git projection` |
| 可重试   | 否               |

## 含义

AST-1202 表示 同一 Asset document 收到重复 materialization。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

一次投影中同一 Asset document 收到重复 materialization

## 建议操作

移除重复的资源副本后重新投影

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
