# AI-7015 Parallel 或 nested tool execution 无法安全合并

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `tool`  |
| 可重试   | 是      |

## 含义

AI-7015 表示 Parallel 或 nested tool execution 无法安全合并。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

target/runtime冲突、fan-out/depth/budget超限、sibling失权，或 canonical join/cleanup不完整

## 建议操作

缩小并发范围，以新的 Run串行重试冲突调用
