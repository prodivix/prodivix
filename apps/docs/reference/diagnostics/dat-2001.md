# DAT-2001 Data operation 引用无法解析

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | DAT       |
| 范围     | 数据      |
| 严重程度 | `error`   |
| 阶段     | `resolve` |
| 可重试   | 否        |

## 含义

DAT-2001 表示 Data operation 引用无法解析。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

DataOperationReference 无法解析，或目标 operation 已不存在于被引用的 Data source

## 建议操作

在 Inspector 中重新选择一个存在的 Data operation，或恢复被删除的 operation
