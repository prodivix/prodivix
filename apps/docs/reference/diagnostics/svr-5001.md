# SVR-5001 已鉴权的 Server Function gateway 不可用

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | SVR                |
| 范围     | 鉴权与服务端运行时 |
| 严重程度 | `error`            |
| 阶段     | `gateway`          |
| 可重试   | 是                 |

## 含义

SVR-5001 表示 已鉴权的 Server Function gateway 不可用。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

authenticated Server Function gateway 暂时不可用

## 建议操作

稍后重试
