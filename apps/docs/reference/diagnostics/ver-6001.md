# VER-6001 Evidence 已过期、撤销或受保护而无法执行 retention 操作

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `warning` |
| 阶段     | `retain`  |
| 可重试   | 否        |

## 含义

VER-6001 表示 Evidence 已过期、撤销或受保护而无法执行 retention 操作。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Evidence 因 TTL/trust revocation 不再满足 Closure，或 release/protection/hold 阻止删除/降级

## 建议操作

重新运行获得当前 Evidence，或由正确 owner 解除 protection

- 触发该错误的操作
- 可复现时的最小文档或配置
