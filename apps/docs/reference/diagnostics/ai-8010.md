# AI-8010 Agent model evaluation statistical floor 未满足

## 快速信息

| 名称     | 说明           |
| -------- | -------------- |
| 前缀     | AI             |
| 范围     | AI 助手        |
| 严重程度 | `error`        |
| 阶段     | `verification` |
| 可重试   | 是             |

## 含义

AI-8010 表示 Agent model evaluation statistical floor 未满足。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

ordinary/critical/high-assurance minimum attempts、confidence bound、sequential stopping rule 或 per-provider/profile threshold 未满足

## 建议操作

使用原 plan/budget继续缺失 attempts；若改变 repetition/threshold，创建新 evaluation plan

- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
