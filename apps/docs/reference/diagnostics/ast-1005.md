# AST-1005 materialization 没有对应 canonical asset document

## 快速信息

| 名称     | 说明              |
| -------- | ----------------- |
| 前缀     | AST               |
| 范围     | 二进制资源        |
| 严重程度 | `error`           |
| 阶段     | `materialization` |
| 可重试   | 否                |

## 含义

AST-1005 表示 materialization 没有对应 canonical asset document。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

materialization 指向的 asset document 不在本次 canonical Workspace 中

## 建议操作

移除失效引用，或重新导入对应资源
