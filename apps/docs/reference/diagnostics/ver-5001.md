# VER-5001 Evidence identity 或 digest 链不匹配

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `fatal`   |
| 阶段     | `promote` |
| 可重试   | 否        |

## 含义

VER-5001 表示 Evidence identity 或 digest 链不匹配。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

workspace/revision/plan/cell/attempt/tool/control/input/artifact/manifest 任一 exact identity 错配

## 建议操作

丢弃 staging 并从正确 Plan 创建新 attempt

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
