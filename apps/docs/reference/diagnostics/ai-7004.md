# AI-7004 Agent network 请求被拒绝

## 快速信息

## 含义

AI-7004 表示 Agent network 请求被拒绝。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

host/method/redirect/DNS/IP/TLS/purpose/size/time 超出 network grant

## 建议操作

检查 network policy；如确需访问，创建显式、最小的新授权
