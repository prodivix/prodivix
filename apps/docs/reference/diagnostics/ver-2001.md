# VER-2001 VerificationPolicy 无效

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | VER      |
| 范围     | 验证闭环 |
| 严重程度 | `error`  |
| 阶段     | `policy` |
| 可重试   | 否       |

## 含义

VER-2001 表示 VerificationPolicy 无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

rule selector/kind 未知、同 specificity 冲突、matrix/budget/retry/evidence requirement 非法

## 建议操作

打开 Policy editor 修复标记规则

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
