# VER-5003 Evidence attestation 无效

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `error`   |
| 阶段     | `promote` |
| 可重试   | 否        |

## 含义

VER-5003 表示 Evidence attestation 无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

issuer/audience/subject/nonce/expiry/signature/key/revision/plan/cell/attempt/toolchain 验证失败或 replay

## 建议操作

使用受控 runner/CI identity 重新运行
