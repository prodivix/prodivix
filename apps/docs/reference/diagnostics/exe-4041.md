# EXE-4041 远端执行或 artifact 未找到

## 快速信息

| 名称     | 说明         |
| -------- | ------------ |
| 前缀     | EXE          |
| 范围     | 远端执行     |
| 严重程度 | `error`      |
| 阶段     | `resolution` |
| 可重试   | 否           |

## 含义

EXE-4041 表示 远端执行或 artifact 未找到。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

远端 execution、artifact 或相关资源已不存在

## 建议操作

重新发起一次执行

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
