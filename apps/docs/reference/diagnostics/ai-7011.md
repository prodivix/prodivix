# AI-7011 Generated artifact candidate 未通过采纳边界

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `tool`  |
| 可重试   | 否      |

## 含义

AI-7011 表示 Generated artifact candidate 未通过采纳边界。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Provider output URL/bytes 未通过 G2 materialize/digest/media/scan/sanitize/provenance，或尝试直接写 Workspace

## 建议操作

查看 Asset scanner/provenance 结果；只审批最终 content-addressed candidate

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
