# BHV-2002 Action 与目标 capability 不兼容

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `error`   |
| 阶段     | `resolve` |
| 可重试   | 否        |

## 含义

BHV-2002 表示 Action 与目标 capability 不兼容。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

target 存在，但不支持 action/observation kind、input type、runtime zone 或 required permission

## 建议操作

选择兼容 action/target，或补齐领域 capability

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
