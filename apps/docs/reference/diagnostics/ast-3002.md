# AST-3002 目标位置已存在同名 Asset

## 快速信息

| 名称     | 说明          |
| -------- | ------------- |
| 前缀     | AST           |
| 范围     | 二进制资源    |
| 严重程度 | `error`       |
| 阶段     | `composition` |
| 可重试   | 否            |

## 含义

AST-3002 表示 目标位置已存在同名 Asset。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

在 Public 资源中创建或导入 Asset 时，目标目录已存在同名条目

## 建议操作

重命名文件，或先删除同名条目后重新导入

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
