# AST-1004 asset bytes 的 digest、size 或 materialization 形状无效

## 快速信息

| 名称     | 说明                |
| -------- | ------------------- |
| 前缀     | AST                 |
| 范围     | 二进制资源          |
| 严重程度 | `error`             |
| 阶段     | `byte verification` |
| 可重试   | 否                  |

## 含义

AST-1004 表示 asset bytes 的 digest、size 或 materialization 形状无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

读取到的 bytes 无法通过 digest/size 校验，或 materialization 结构非法

## 建议操作

重新上传该资源；若来自本地副本，先执行 Workspace 恢复再重试
