# VER-1001 VerificationImpactSet 已失效或输入错配

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | VER      |
| 范围     | 验证闭环 |
| 严重程度 | `error`  |
| 阶段     | `impact` |
| 可重试   | 是       |

## 含义

VER-1001 表示 VerificationImpactSet 已失效或输入错配。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

before/after revision、semantic schema、provider set 或 stored impact digest 不匹配

## 建议操作

重新构建 Impact 和 Plan

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
