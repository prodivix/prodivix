# BHV-3001 BehaviorScenarioProgram 编译失败

## 快速信息

| 名称     | 说明      |

| 前缀     | BHV       |

## 含义

BHV-3001 表示 BehaviorScenarioProgram 编译失败。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

subscenario cycle、unsupported instruction、domain lowering、SourceTrace 或 canonical serialization 失败

## 建议操作

打开 compile details 并定位首个失败步骤
