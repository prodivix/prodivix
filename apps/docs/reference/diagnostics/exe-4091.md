# EXE-4091 远端请求幂等 identity 冲突

## 快速信息

| 名称     | 说明          |
| -------- | ------------- |
| 前缀     | EXE           |
| 范围     | 远端执行      |
| 严重程度 | `error`       |
| 阶段     | `idempotency` |
| 可重试   | 否            |

## 含义

EXE-4091 表示 远端请求幂等 identity 冲突。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

请求的幂等 identity 与远端已存在的请求冲突

## 建议操作

重新发起一次新的执行，不要重复提交同一请求
