# AI-6010 Provider capability qualification 缺失或已过期

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `task`  |
| 可重试   | 是      |

## 含义

AI-6010 表示 Provider capability qualification 缺失或已过期。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

exact provider/model/capability/policy slice 未取得 qualification，或 profile/probe/evaluation 已过期

## 建议操作

选择已 qualification 的 capability/model，或运行对应 admission/release evaluation

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
