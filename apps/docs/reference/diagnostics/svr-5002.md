# SVR-5002 Server Function 输出不符合边界契约

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | SVR                |
| 范围     | 鉴权与服务端运行时 |
| 严重程度 | `error`            |
| 阶段     | `output boundary`  |
| 可重试   | 否                 |

## 含义

SVR-5002 表示 Server Function 输出不符合边界契约。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

adapter output 或响应不符合 schema 或 strict bridge contract

## 建议操作

携带错误码与操作上报；该失败通常表示 Server Function 实现需要修正

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
