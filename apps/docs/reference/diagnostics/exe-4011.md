# EXE-4011 远端执行需要授权

## 快速信息

| 名称     | 说明            |
| -------- | --------------- |
| 前缀     | EXE             |
| 范围     | 远端执行        |
| 严重程度 | `error`         |
| 阶段     | `authorization` |
| 可重试   | 否              |

## 含义

EXE-4011 表示 远端执行需要授权。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

远端执行请求缺少有效授权

## 建议操作

重新登录后再次执行
