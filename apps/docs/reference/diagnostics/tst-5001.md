# TST-5001 项目测试失败

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | TST       |
| 范围     | 工程测试  |
| 严重程度 | `error`   |
| 阶段     | `execute` |
| 可重试   | 否        |

## 含义

TST-5001 表示 项目测试失败。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Test provider 取得有效 canonical report，且一个或多个 test file/case 失败

## 建议操作

打开 Test report 与 Console，检查失败用例、SourceTrace 和断言信息后重新运行

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
