## 含义

AI-6002 表示 Agent budget 已耗尽。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

token/media/tool/compute/storage usage、cost、context、model invocation、tool call、repair、transaction、artifact 或 elapsed-time 任一 hard ceiling 已耗尽

## 建议操作

审阅已用预算和当前结果；如确需继续，以新的人类授权创建 Task/Run
