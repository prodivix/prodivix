# EXE-5003 已脱敏的远端内部失败

## 快速信息

| 名称     | 说明        |
| -------- | ----------- |
| 前缀     | EXE         |
| 范围     | 远端执行    |
| 严重程度 | `error`     |
| 阶段     | `transport` |
| 可重试   | 否          |

## 含义

EXE-5003 表示 已脱敏的远端内部失败。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

远端 runner 内部失败，且只返回脱敏后的稳定错误分类

## 建议操作

是否值得重试以响应中的 `retryable` 标记为准；若不可重试，携带错误码与操作上报

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
