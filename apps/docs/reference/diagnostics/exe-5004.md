# EXE-5004 Secret 边界 fail closed

## 快速信息

| 名称     | 说明              |
| -------- | ----------------- |
| 前缀     | EXE               |
| 范围     | 远端执行          |
| 严重程度 | `fatal`           |
| 阶段     | `secret boundary` |
| 可重试   | 否                |

## 含义

EXE-5004 表示 Secret 边界 fail closed。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

isolated Secret 解析不可用或被拒绝，或执行输出中检出受保护材料而被阻断

## 建议操作

检查环境与 Secret 配置后重新发起执行，不要重复运行同一次输出

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
