# BHV-9001 未分类的 Behavior 异常

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | BHV                |
| 范围     | 行为场景           |
| 严重程度 | `error`            |
| 阶段     | `runtime-selected` |
| 可重试   | 否                 |

## 含义

BHV-9001 表示 未分类的 Behavior 异常。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

未匹配到稳定语义的内部异常

## 建议操作

复制 code、request/attempt id 和安全详情后上报

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
