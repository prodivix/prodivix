# AST-3001 当前 composition 没有授权的 blob materialization adapter

## 快速信息

| 名称     | 说明          |
| -------- | ------------- |
| 前缀     | AST           |
| 范围     | 二进制资源    |
| 严重程度 | `error`       |
| 阶段     | `composition` |
| 可重试   | 是            |

## 含义

AST-3001 表示 当前 composition 没有授权的 blob materialization adapter。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

当前 Browser、Export、Test 或 Run composition 没有可授权的 blob materialization adapter

## 建议操作

重新登录或等待 Workspace 同步完成后重试
