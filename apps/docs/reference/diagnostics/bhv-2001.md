# BHV-2001 行为目标无法唯一解析

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `error`   |
| 阶段     | `resolve` |
| 可重试   | 否        |

## 含义

BHV-2001 表示 行为目标无法唯一解析。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

semantic target missing、ambiguous、revision/provider snapshot 不匹配，且不能 exact resolve

## 建议操作

在 target picker 中重新选择或修复已删除目标

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
