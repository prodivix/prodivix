# AI-7013 Retrieval source 或 index 不可用于当前 Context

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `tool`  |
| 可重试   | 是      |

## 含义

AI-7013 表示 Retrieval source 或 index 不可用于当前 Context。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

source/index corpus revision、chunker、embedding/ranker、scope、retention/deletion 缺失、stale 或 poisoning

## 建议操作

重建 exact corpus index，或移除不可信 source 并重新运行 retrieval

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
