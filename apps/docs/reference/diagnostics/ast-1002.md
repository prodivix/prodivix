# AST-1002 同一 asset document 收到多个 materialization

## 快速信息

| 名称     | 说明              |
| -------- | ----------------- |
| 前缀     | AST               |
| 范围     | 二进制资源        |
| 严重程度 | `error`           |
| 阶段     | `materialization` |
| 可重试   | 否                |

## 含义

AST-1002 表示 同一 asset document 收到多个 materialization。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

同一 asset document 在一次编译或提交中收到多个 materialization

## 建议操作

移除重复导入的同一资源副本后重新运行
