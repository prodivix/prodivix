# AST-1102 download-only media 缺少 attachment-capable isolated origin

## 快速信息

| 名称     | 说明              |
| -------- | ----------------- |
| 前缀     | AST               |
| 范围     | 二进制资源        |
| 严重程度 | `error`           |
| 阶段     | `public delivery` |
| 可重试   | 否                |

## 含义

AST-1102 表示 download-only media 缺少 attachment-capable isolated origin。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

download-only 媒体没有可用的 attachment-capable isolated origin

## 建议操作

配置可用的隔离交付源后重试
