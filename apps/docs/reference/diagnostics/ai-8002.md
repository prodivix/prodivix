# AI-8002 Agent repair 已达到上限

## 快速信息

| 名称     | 说明           |
| -------- | -------------- |
| 前缀     | AI             |
| 范围     | AI 助手        |
| 严重程度 | `error`        |
| 阶段     | `verification` |
| 可重试   | 否             |

## 含义

AI-8002 表示 Agent repair 已达到上限。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

repair round 或相关 token/cost/time/transaction budget 已耗尽

## 建议操作

审阅全部失败 lineage，人工决定下一步

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
