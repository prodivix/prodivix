# EXE-5002 远端 transport 请求超时

## 快速信息

| 名称     | 说明        |
| -------- | ----------- |
| 前缀     | EXE         |
| 范围     | 远端执行    |
| 严重程度 | `error`     |
| 阶段     | `transport` |
| 可重试   | 是          |

## 含义

EXE-5002 表示 远端 transport 请求超时。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

远端 transport 请求在预算内没有返回

## 建议操作

稍后重试；若反复超时，检查网络后再执行
