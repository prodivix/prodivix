# VER-3004 VerificationPlan 超出预算

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | VER      |
| 范围     | 验证闭环 |
| 严重程度 | `error`  |
| 阶段     | `plan`   |
| 可重试   | 否       |

## 含义

VER-3004 表示 VerificationPlan 超出预算。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

required cells 在去重和显式 critical subset 后仍超过 compute/time/artifact/concurrency budget

## 建议操作

调整 canonical Policy、拆分 scope 或创建有界 exemption

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
