# VER-3003 Required cell 依赖无法满足

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | VER      |
| 范围     | 验证闭环 |
| 严重程度 | `error`  |
| 阶段     | `plan`   |
| 可重试   | 是       |

## 含义

VER-3003 表示 Required cell 依赖无法满足。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

fixture、baseline、build、permission、artifact input 或 prerequisite missing/blocked

## 建议操作

修复对应 dependency 后重建/执行 Plan

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
