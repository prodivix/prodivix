# AI-6001 AgentTask base revision 已过期

## 快速信息

## 含义

AI-6001 表示 AgentTask base revision 已过期。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Task/Run/Context/Proposal 的 base revision 与 current authorized Workspace revision 不一致

## 建议操作

在最新 Workspace revision 上创建新 Task 或重新生成 Proposal
