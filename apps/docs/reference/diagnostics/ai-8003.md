# AI-8003 Agent audit 不完整

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `audit` |
| 可重试   | 否      |

## 含义

AI-8003 表示 Agent audit 不完整。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

event sequence/fence/hash、required identity 或 sanitized manifest 缺失/不一致

## 建议操作

阻止提交或关闭 Run，检查 Agent service recovery

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
