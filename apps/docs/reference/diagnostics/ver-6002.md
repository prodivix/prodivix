# VER-6002 VerificationClosure 不完整或已失效

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | VER      |
| 范围     | 验证闭环 |
| 严重程度 | `error`  |
| 阶段     | `close`  |
| 可重试   | 否       |

## 含义

VER-6002 表示 VerificationClosure 不完整或已失效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

required cell 的 `VerificationCellStatus` 不是 `passed`（见 ADR 57「状态 taxonomy」），或 revision/policy/plan/evidence freshness 已变化

## 建议操作

打开 Closure 查看具体 cell 和 impact path，修复后重新执行/提升 Evidence

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
