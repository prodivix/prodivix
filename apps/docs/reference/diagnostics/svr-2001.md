# SVR-2001 Server Function 输入不符合 canonical JSON Schema

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | SVR                |
| 范围     | 鉴权与服务端运行时 |
| 严重程度 | `error`            |
| 阶段     | `input preflight`  |
| 可重试   | 否                 |

## 含义

SVR-2001 表示 Server Function 输入不符合 canonical JSON Schema。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

调用输入不符合 canonical JSON Schema

## 建议操作

按 Server Function 的输入契约修正参数后重试

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
