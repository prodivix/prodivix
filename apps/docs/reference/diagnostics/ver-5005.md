# VER-5005 Artifact promotion 或安全校验失败

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `error`   |
| 阶段     | `promote` |
| 可重试   | 是        |

## 含义

VER-5005 表示 Artifact promotion 或安全校验失败。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

upload/digest/media/structural scan/active content/path/archive/image budget/store/atomic finalize 失败

## 建议操作

根据安全详情修复 artifact 或恢复存储后幂等重试

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
