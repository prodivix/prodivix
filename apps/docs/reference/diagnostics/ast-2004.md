# AST-2004 旧 JSON-only import 未使用 upload-aware protocol

## 快速信息

| 名称     | 说明            |
| -------- | --------------- |
| 前缀     | AST             |
| 范围     | 二进制资源      |
| 严重程度 | `error`         |
| 阶段     | `blob boundary` |
| 可重试   | 否              |

## 含义

AST-2004 表示 旧 JSON-only import 未使用 upload-aware protocol。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

含 Asset 的旧 JSON-only local import 未使用 upload-aware protocol

## 建议操作

使用当前版本的导入入口重新导入项目
