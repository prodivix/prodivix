# AST-3102 交付被 transform、媒体或内容策略拒绝

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | AST        |
| 范围     | 二进制资源 |
| 严重程度 | `error`    |
| 阶段     | `delivery` |
| 可重试   | 否         |

## 含义

AST-3102 表示 交付被 transform、媒体或内容策略拒绝。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

transform、media 或 content policy 拒绝交付，或 scanner 判定 quarantine

## 建议操作

更换资源或改用受支持的媒体类型后重新上传

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
