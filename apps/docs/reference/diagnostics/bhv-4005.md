# BHV-4005 Runtime control 未完整应用

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `error`   |
| 阶段     | `execute` |
| 可重试   | 否        |

## 含义

BHV-4005 表示 Runtime control 未完整应用。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

provider 无法应用 required clock/random/network/storage/render/motion control 或 applied digest 不匹配

## 建议操作

选择支持该 control profile 的 provider，或显式调整 Policy

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
