# AST-2001 blob 上传请求无效

## 快速信息

| 名称     | 说明            |
| -------- | --------------- |
| 前缀     | AST             |
| 范围     | 二进制资源      |
| 严重程度 | `error`         |
| 阶段     | `blob boundary` |
| 可重试   | 否              |

## 含义

AST-2001 表示 blob 上传请求无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

digest、media type、size、bytes、multipart 形状或 request budget 无效

## 建议操作

检查文件大小与类型限制后重新上传

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
