# SVR-3003 mutation 有界容量耗尽

## 快速信息

| 名称     | 说明               |
| -------- | ------------------ |
| 前缀     | SVR                |
| 范围     | 鉴权与服务端运行时 |
| 严重程度 | `error`            |
| 阶段     | `mutation budget`  |
| 可重试   | 否                 |

## 含义

SVR-3003 表示 mutation 有界容量耗尽。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

一次 execution 的 state 或 replay 有界容量耗尽

## 建议操作

重新开始一次执行；若反复出现，减少单次执行中的 mutation 数量

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
