# AST-2002 授权范围内找不到 blob

## 快速信息

| 名称     | 说明            |
| -------- | --------------- |
| 前缀     | AST             |
| 范围     | 二进制资源      |
| 严重程度 | `error`         |
| 阶段     | `blob boundary` |
| 可重试   | 否              |

## 含义

AST-2002 表示 授权范围内找不到 blob。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

授权读取找不到 blob，或 Workspace commit 引用了尚未上传的 blob

## 建议操作

先完成资源上传，再重新提交或重新打开该 Workspace

- 触发该错误的操作
- 可复现时的最小文档或配置
