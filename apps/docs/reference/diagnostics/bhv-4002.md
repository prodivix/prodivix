# BHV-4002 行为条件等待超时

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `error`   |
| 阶段     | `execute` |
| 可重试   | 否        |

## 含义

BHV-4002 表示 行为条件等待超时。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

typed observation/settle/barrier 在 virtual/real safety budget 内未成立

## 建议操作

检查 condition、pending owner、fixture 和 timeout policy，不用固定 sleep 绕过

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
