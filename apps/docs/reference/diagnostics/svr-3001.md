# SVR-3001 live mutation 缺少允许的 Origin 或 mutation intent

## 快速信息

| 名称     | 说明                     |
| -------- | ------------------------ |
| 前缀     | SVR                      |
| 范围     | 鉴权与服务端运行时       |
| 严重程度 | `error`                  |
| 阶段     | `mutation request guard` |
| 可重试   | 否                       |

## 含义

SVR-3001 表示 live mutation 缺少允许的 Origin 或 mutation intent。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

live mutation 请求缺少 exact allowed Origin 或显式 mutation intent

## 建议操作

从受支持的运行入口重新发起该操作
