# AST-1101 active content 缺少 sanitizer 与 isolated-origin policy

## 快速信息

| 名称     | 说明              |
| -------- | ----------------- |
| 前缀     | AST               |
| 范围     | 二进制资源        |
| 严重程度 | `error`           |
| 阶段     | `public delivery` |
| 可重试   | 否                |

## 含义

AST-1101 表示 active content 缺少 sanitizer 与 isolated-origin policy。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

需要公开交付的 active content 资源没有可用 sanitizer 与 isolated-origin 策略

## 建议操作

改用受支持的媒体类型，或在交付配置中启用隔离源
