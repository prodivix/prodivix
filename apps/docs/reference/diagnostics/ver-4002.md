# VER-4002 EvidenceCandidate 无效或超出预算

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `error`   |
| 阶段     | `execute` |
| 可重试   | 否        |

## 含义

VER-4002 表示 EvidenceCandidate 无效或超出预算。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

candidate codec、count/depth/bytes、artifact manifest、event ordering 或 redaction report 无效

## 建议操作

修复 adapter 输出后重跑

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
