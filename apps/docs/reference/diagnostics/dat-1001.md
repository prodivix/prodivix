# DAT-1001 Data source document 无效

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | DAT        |
| 范围     | 数据       |
| 严重程度 | `error`    |
| 阶段     | `validate` |
| 可重试   | 否         |

## 含义

DAT-1001 表示 Data source document 无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

DataSourceDocument 无法通过 current contract 或 wire codec 校验，包括 source、schema、operation、policy 或引用式 configuration 形状无效

## 建议操作

打开 Data source，修正被标记的 schema、operation 或 configuration 后重新保存
