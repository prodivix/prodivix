# AI-8011 Holdout、grader 或 human review evidence 无效

## 快速信息

| 名称     | 说明           |
| -------- | -------------- |
| 前缀     | AI             |
| 范围     | AI 助手        |
| 严重程度 | `error`        |
| 阶段     | `verification` |
| 可重试   | 否             |

## 含义

AI-8011 表示 Holdout、grader 或 human review evidence 无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

protected holdout泄漏/被替换、post-result grader/threshold修改、sole LLM judge、自评，或 required blind human rubric缺失

## 建议操作

轮换受污染 holdout，冻结新 grader/review plan并重跑受影响 slice

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
