# BHV-4006 行为运行状态未能安全清理

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `fatal`   |
| 阶段     | `execute` |
| 可重试   | 是        |

## 含义

BHV-4006 表示 行为运行状态未能安全清理。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

cancel/terminal 后 storage、service worker、timer、effect、worker 或 auth state residual canary 失败

## 建议操作

销毁并重建运行环境后重试

- 触发该错误的操作
- 可复现时的最小文档或配置
