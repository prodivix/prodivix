# EXE-4092 需要按 authoritative status 恢复

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | EXE        |
| 范围     | 远端执行   |
| 严重程度 | `error`    |
| 阶段     | `recovery` |
| 可重试   | 是         |

## 含义

EXE-4092 表示 需要按 authoritative status 恢复。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

cursor、provider 或 status 不再连续，必须重新读取权威状态后恢复

## 建议操作

等待编辑器自动恢复；若长时间未恢复，重新打开执行面板
