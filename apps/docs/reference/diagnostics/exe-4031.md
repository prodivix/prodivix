# EXE-4031 远端执行操作被拒绝

## 快速信息

| 名称     | 说明            |
| -------- | --------------- |
| 前缀     | EXE             |
| 范围     | 远端执行        |
| 严重程度 | `error`         |
| 阶段     | `authorization` |
| 可重试   | 否              |

## 含义

EXE-4031 表示 远端执行操作被拒绝。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

当前身份不允许在该 Workspace 上执行此远端操作

## 建议操作

联系 Workspace 所有者申请对应执行权限
