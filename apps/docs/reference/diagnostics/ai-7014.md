# AI-7014 MCP、computer use 或 managed-agent capability 被拒绝

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `tool`  |
| 可重试   | 否      |

## 含义

AI-7014 表示 MCP、computer use 或 managed-agent capability 被拒绝。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

unpinned MCP、computer-use 作者态/approval 操作、现有用户 session访问，或 opaque managed-agent delegation

## 建议操作

改用 pinned descriptor、disposable read-only Verification 或 typed domain proposal
