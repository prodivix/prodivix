# BHV-4003 确定性 replay 发生分歧

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | BHV      |
| 范围     | 行为场景 |
| 严重程度 | `error`  |

## 含义

BHV-4003 表示 确定性 replay 发生分歧。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

相同 Program/control/fixture/tool identity 下的 schedule、observation 或 effect sequence 首次不一致

## 建议操作

打开 divergence 位置，检查未受控 random/time/network/async source
