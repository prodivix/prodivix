# AI-6011 Provider inference state 或 effective Context 不可证明

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `task`  |
| 可重试   | 否      |

## 含义

AI-6011 表示 Provider inference state 或 effective Context 不可证明。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

ambient memory、cross-tenant cache、unknown compaction、parent state、opaque continuation 或 retention/deletion 无法绑定 exact receipt

## 建议操作

改用 stateless/storage-disabled profile，或移除不允许披露的 Context
