# VER-4001 Verification adapter 失败

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `error`   |
| 阶段     | `execute` |
| 可重试   | 是        |

## 含义

VER-4001 表示 Verification adapter 失败。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

adapter preflight/prepare/execute/normalize/cleanup 失败、tool schema 未知或 exit/result 不一致

## 建议操作

查看 adapter/toolchain 和安全日志，修复环境或更新兼容 adapter
