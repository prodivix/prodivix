# BHV-5001 Recorder 无法生成可提交的语义步骤

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `warning` |
| 阶段     | `record`  |
| 可重试   | 否        |

## 含义

BHV-5001 表示 Recorder 无法生成可提交的语义步骤。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

raw event 没有 semantic target、候选歧义、敏感输入或事件预算超限

## 建议操作

手动选择目标/action，或丢弃该 draft

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
