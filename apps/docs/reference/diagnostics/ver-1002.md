# VER-1002 Impact provider 不完整，已扩大验证范围

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `warning` |
| 阶段     | `impact`  |
| 可重试   | 否        |

## 含义

VER-1002 表示 Impact provider 不完整，已扩大验证范围。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

domain contributor 缺失、graph budget exceeded、before revision 不可用或 completeness 降级

## 建议操作

检查被扩大范围；若 required budget 超限，修复 provider 或调整显式 Policy

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
