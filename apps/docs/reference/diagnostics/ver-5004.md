# VER-5004 Evidence 或 baseline 不兼容，无法比较

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | VER       |
| 范围     | 验证闭环  |
| 严重程度 | `warning` |
| 阶段     | `compare` |
| 可重试   | 否        |

## 含义

VER-5004 表示 Evidence 或 baseline 不兼容，无法比较。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

family/target/browser/viewport/DPR/motion/font/tool/normalizer/baseline/control compatibility 不满足

## 建议操作

选择兼容 Evidence/baseline 或重新运行对应 cell

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
