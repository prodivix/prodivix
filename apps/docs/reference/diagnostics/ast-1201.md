# AST-1201 canonical Asset 缺少 exact verified materialization

## 快速信息

| 名称     | 说明             |
| -------- | ---------------- |
| 前缀     | AST              |
| 范围     | 二进制资源       |
| 严重程度 | `error`          |
| 阶段     | `git projection` |
| 可重试   | 是               |

## 含义

AST-1201 表示 canonical Asset 缺少 exact verified materialization。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Git/LFS 投影时 canonical Asset 没有 exact verified materialization

## 建议操作

等待资源同步完成后重新投影；若长期不可用，重新导入该资源
