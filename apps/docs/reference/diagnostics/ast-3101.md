# AST-3101 隔离交付宿主暂不可用

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | AST        |
| 范围     | 二进制资源 |
| 严重程度 | `error`    |
| 阶段     | `delivery` |
| 可重试   | 是         |

## 含义

AST-3101 表示 隔离交付宿主暂不可用。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Host、scanner readiness、病毒库时效、策略锁或有界 session capacity 不可用

## 建议操作

稍后重试；若持续失败，联系管理员确认交付宿主状态

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
