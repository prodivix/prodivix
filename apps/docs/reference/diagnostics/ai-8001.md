# AI-8001 Agent Verification Closure 未满足

## 快速信息

## 含义

AI-8001 表示 Agent Verification Closure 未满足。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

committed revision 的 Closure 为 incomplete/unsatisfied/stale/incompatible，或 required Evidence 缺失

## 建议操作

审阅失败 Evidence；选择人工修复、审批 bounded Agent repair 或 rollback
