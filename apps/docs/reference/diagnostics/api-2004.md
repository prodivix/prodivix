# API-2004 密码重置链接无效

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | API      |
| 范围     | 后端/API |
| 严重程度 | `error`  |
| 阶段     | `auth`   |
| 可重试   | 否       |

## 含义

API-2004 表示 密码重置链接无效。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

密码重置令牌格式错误、已过期、已使用，或被新申请的链接替换

## 建议操作

重新申请重置邮件并使用最新链接

- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
