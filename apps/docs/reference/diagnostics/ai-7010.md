# AI-7010 多模态 Context 或 transformation 被拒绝

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `tool`  |
| 可重试   | 否      |

## 含义

AI-7010 表示 多模态 Context 或 transformation 被拒绝。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

media source/digest/type/transform/omission/limit 无法验证，或 image/PDF/QR/OCR/metadata 指令尝试提升 authority

## 建议操作

检查原始媒体、转换与遗漏范围；移除恶意或不支持内容后重建 Context

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
