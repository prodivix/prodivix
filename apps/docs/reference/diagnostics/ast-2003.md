# AST-2003 blob metadata 或 bytes 与请求冲突

## 快速信息

| 名称     | 说明            |
| -------- | --------------- |
| 前缀     | AST             |
| 范围     | 二进制资源      |
| 严重程度 | `error`         |
| 阶段     | `blob boundary` |
| 可重试   | 否              |

## 含义

AST-2003 表示 blob metadata 或 bytes 与请求冲突。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

同一 Workspace/digest 的已存 metadata 或 bytes 与本次请求冲突

## 建议操作

确认要保留的版本后重新导入

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
