# BHV-4001 行为步骤失败

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `error`   |
| 阶段     | `execute` |
| 可重试   | 否        |

## 含义

BHV-4001 表示 行为步骤失败。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

action 返回 terminal failure，或 declared postcondition 得到明确 false

## 建议操作

打开 step、domain diagnostic、ReplayRecord 和 SourceTrace

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
