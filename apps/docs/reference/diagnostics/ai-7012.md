# AI-7012 Hosted tool 或动态 capability 未获授权

## 快速信息

| 名称     | 说明    |
| -------- | ------- |
| 前缀     | AI      |
| 范围     | AI 助手 |
| 严重程度 | `error` |
| 阶段     | `tool`  |
| 可重试   | 否      |

## 含义

AI-7012 表示 Hosted tool 或动态 capability 未获授权。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

Provider-hosted/programmatic/nested tool 无 exact descriptor/registry/call receipt，或动态发现 registry 外工具

## 建议操作

使用已 pin 的 exact descriptor/registry；缩小工具与 effect scope

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
