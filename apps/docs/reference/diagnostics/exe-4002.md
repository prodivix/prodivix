# EXE-4002 远端请求或响应未通过严格 codec 校验

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | EXE      |
| 范围     | 远端执行 |
| 严重程度 | `error`  |
| 阶段     | `codec`  |
| 可重试   | 否       |

## 含义

EXE-4002 表示 远端请求或响应未通过严格 codec 校验。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

远端 runner 拒绝了执行请求，或响应无法通过 strict wire codec 解码

## 建议操作

重新发起执行；若持续失败，携带错误码与操作上报

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
