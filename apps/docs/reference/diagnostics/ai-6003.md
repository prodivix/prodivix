# AI-6003 AgentRun callback 已失权

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | AI        |
| 范围     | AI 助手   |
| 严重程度 | `warning` |
| 阶段     | `task`    |
| 可重试   | 否        |

## 含义

AI-6003 表示 AgentRun callback 已失权。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

cancel、timeout、retry 或 recovery 后收到旧 generation 的 model/tool/commit callback

## 建议操作

无；系统已拒绝过期结果
