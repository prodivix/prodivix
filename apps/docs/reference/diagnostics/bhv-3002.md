# BHV-3002 行为程序超出预算

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `error`   |
| 阶段     | `compile` |
| 可重试   | 否        |

## 含义

BHV-3002 表示 行为程序超出预算。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

instruction、depth、branch、repeat、timeout、fixture、baseline 或 Program bytes 超出上限

## 建议操作

拆分 Scenario、降低有界循环或缩小受控 fixture

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
