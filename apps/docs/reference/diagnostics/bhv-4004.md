# BHV-4004 行为运行请求了禁止的网络或敏感能力

## 快速信息

| 名称     | 说明      |
| -------- | --------- |
| 前缀     | BHV       |
| 范围     | 行为场景  |
| 严重程度 | `fatal`   |
| 阶段     | `execute` |
| 可重试   | 否        |

## 含义

BHV-4004 表示 行为运行请求了禁止的网络或敏感能力。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

required run 发起 live egress、读取 production Secret/credential、越权 storage 或 Workspace write

## 建议操作

改用受控 fixture/typed gateway，检查 Scenario 与 domain capability

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
