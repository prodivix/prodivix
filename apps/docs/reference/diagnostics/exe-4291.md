# EXE-4291 远端执行配额已超出

## 快速信息

| 名称     | 说明     |
| -------- | -------- |
| 前缀     | EXE      |
| 范围     | 远端执行 |
| 严重程度 | `error`  |
| 阶段     | `quota`  |
| 可重试   | 否       |

## 含义

EXE-4291 表示 远端执行配额已超出。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

远端执行超过当前配额

## 建议操作

等待配额恢复或联系管理员调整配额

## 上报时提供

- 错误码和 requestId
- 当前项目或工作区 ID
- 触发该错误的操作
- 可复现时的最小文档或配置
