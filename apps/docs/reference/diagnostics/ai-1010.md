# AI-1010 Provider baseURL 非法

## 快速信息

| 名称     | 说明       |
| -------- | ---------- |
| 前缀     | AI         |
| 范围     | AI 助手    |
| 严重程度 | `error`    |
| 阶段     | `provider` |
| 可重试   | 否         |

## 含义

AI-1010 表示 Provider baseURL 非法。请先确认当前页面、项目状态和最近操作，再按建议操作处理。

## 触发条件

配置了 API key，但 baseURL 不是合法绝对 URL，或既非 `https:` 也非回环地址

## 建议操作

改用 `https://` 的 baseURL，或使用 `http://localhost` 等本机地址
